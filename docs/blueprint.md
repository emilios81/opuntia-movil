# **App Name**: RupestreAI

## Core Features:

- Image Upload and Display: Allow users to upload an image of rock art and display the original image.
- Preset Image Enhancements: Apply preset filters (Red, White, Bichrome, Black, YBK, LDS, CLAHE, Pigment Mapping) to enhance the rock art image.
- Intensity Adjustment: Provide a slider to adjust the intensity of the applied enhancement filters.
- Image Processing AI tool: Apply enhancement filter based on image and a LLM selecting an appropriate filter
- Image Comparison: Enable users to compare the original and enhanced images using a slider.
- Download Enhanced Image: Allow users to download the enhanced image.

## Style Guidelines:

- Primary color: Deep brown (#372A20) to evoke a sense of earth, history, and grounding, referencing the natural environments where rock art is found.
- Background color: Very light brown (#F2E9E1), almost white, providing a clean, neutral backdrop that allows the rock art imagery to stand out.
- Accent color: Muted red-orange (#C06042), analogous to the primary brown but with increased brightness and saturation, for highlighting key interactive elements.
- Body and headline font: 'Alegreya', a serif classification, should be used throughout for a vintage, elegant feel and good readability.
- Code font: 'Source Code Pro' for any displayed code snippets or technical details.
- Use clear, minimalist icons to represent the different enhancement filters. Icons should be easily distinguishable and complement the overall aesthetic.
- Maintain a clean and intuitive layout. Image upload and preview should be the focal point, with enhancement options easily accessible on the side.
- Use subtle animations and transitions for filter application and slider movement to enhance user experience without being distracting.
